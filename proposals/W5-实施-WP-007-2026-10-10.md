## 一、门链静态具名化（`src/Wanxiangshu/OpenCode/Tools/ToolRegistry.fs`）

组合入口 `executeGate` 一处可见地按固定顺序调用六道具名门，普通调用，无 dynamic middleware、列表 fold 或注册表：

1. `providerToolBoundary` — 原样提升；死码保留（当前恒 `Ok()`）。
2. `accountingStage` — `beginToolExecution` / `endToolExecution`；SessionId 空白时不记账。
3. `ablationStage` — 命中 `AblationGate.toolDenied` → `tool/registry/denied-ablation`。
4. `replicaStage` — 仅放行 `js-predictor`；其余 `tool/registry/denied-strength`。
5. `admissionStage` → `officeStage` / `attachmentStage` 分流。
6. `managerFactsStage` — frozen（仅留 Join/Finality）与 `OfficeCapability.isAllowedForManagerFacts` 收口。

每门只读窄输入 record `ToolGateFacts`（7 字段，`ToolRuntimeScope` 与 `create` 回调填充）；stage 不接触整个 scope。
拒绝形态与 code 契约逐字节保持：`denied` / `carriesRefusalCode`（仅 mv / rm）/ `denyRole` / `denyTaskState`。
