# js- 编程面：暂停-恢复与 as-is 写语义的设计依据

2026-10-16 定稿。**本文是决策依据，不是活指南**。现行合同在 `requirements/repository-programming/WHAT.md`（[024]–[036]）、`requirements/process-execution/WHAT.md` 与 `wanxiangli/src/program/AGENTS.md`；字段名现为 `intent`，期限为 `UTF8Bytes(intent) × 50ms`，恢复入口为 `this.unpark(name, value?)`。

保留本文的理由只有一个：当年排除过的路径与代价写在这里，避免同类改动重新交学费。

## 1. 用户拍板的结论

1. 续延模型：**保活现场 + 编排层恢复**。程序对恢复机制零感知；恢复是 AI 的动作，不是程序的成员。
2. 写语义：全局翻转为 **as-is**。每笔写成功即落盘，跨笔不回滚；终止与挂起都是事实分界线。单笔 mutation 原子性（MutationFs 文件层）保留，`FILE_CHANGED` 校验点移到每次写前。
3. finalizer：abandon/reap 以 ABANDONED rejection 展开程序栈，用原生 `try/finally` 收尾，零新 API。
4. 收尾三态：unpark → Done；abandon/reap → Abandoned；进程重启 → 现场消失（durable 只留审计痕迹）。不存在无声无息的结束。
5. 泄漏兜底：交付门禁逼表态 + 每回合提醒（并入既有 Pair Hint 通道）+ 会话终结 reap。
6. 句柄与 subagent 同命：随进程死亡重置，现场是进程内活物，不序列化。
7. 新增 `rm` / `mv` 成员，命名对齐仓库既有 `mv`/`rm`。

## 2. 为什么不是别的做法

| 被否决的做法 | 否决理由 |
| --- | --- |
| 决定性重放（程序文本 + 注入值序列重放） | 把「可确定性重放」的终身税压给每个程序作者：`Math.random`、`Date.now`、闭包状态都能让恢复失败。 |
| generator 驱动器 / CPS 编译 | 绑架程序写法，自造解释器。 |
| 同步阻塞 | 单线程事件循环死锁。 |
| 回调式 `on_abandon(fn)` | 新 API，回调调用栈环境诡异，表达力不如原生栈展开。 |
| 程序内恢复成员（如 `js.resume`） | 黑盒视角里恢复是 AI 的动作；成员形态会把恢复逻辑混进程序文本。 |
| 现场 durable 序列化 | 活栈不可序列化是物理边界。 |
| 保留 All-or-Nothing | 失败时前 9 笔改动被悄悄丢掉，AI 对世界状态一无所知，只能全部重跑。 |

对应的反事实：复杂度应落在系统侧（现场表、竞速、reap 是一次性成本），而不是程序侧（终身税）。

## 3. 当年核实过、今天仍成立的结构事实

- 沙箱是 `node:vm` 的 `createContext` + `runInContext`，程序包成 async IIFE；双层超时（同步段 vm timeout，异步段注入 Proxy 查 `Date.now() > deadline`）。
- 工具级挂起形态：执行中的程序挂起时，该次工具调用返回顶级 parked 载荷；恢复调用若程序再次 park，返回新载荷，语义与首次一致。
- 现行实现里这套语义由 `wanxiangli/program`（私有 Run、暂停代际、结算）与 `wanxiangli/runtime`（进程、文件、输出）承担，宿主只做准入与投影。
- 当年宿主的 `mv`/`rm` 与原生 `read`/`write`/`edit` 无路径边界、无 `FILE_CHANGED`、无 durable 记账；这是既有差距，不是应然。`edit`/`rewrite` 现已在编程面退役，改由 `cat` + `where`/`whereAll` + `write` 组合。

## 4. 没写进合同的旧细节

当年稿里的 `HANDLE_UNKNOWN`、`CANNOT_PARK_WHILE_ABANDONING`、10 秒展开窗口、并发现场上限 8、`{ unpark: { handle, value } }` 编排层入参，现行对应为：名字登记与 `NAME_TAKEN`（[033]）、放弃期间禁止 park 并报 `CANNOT_PARK_WHILE_ABANDONING`（[035]）、请求期限到期真实暂停（[030]）、`unpark(name, value?)`（[032]）。展开窗口与并发现场上限没有写进现行 WHAT，实现值以 `wanxiangli/src/program/Run.fs` 为准，本文不重复。
