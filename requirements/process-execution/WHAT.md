# process-execution — WHAT

## [001] 模型命令执行入口

模型通过 `todowrite-for-ROLE` 执行命名程序，顶层参数严格为三个必填字符串 name、program、intent。Exec 权限投影 `call(command)`、`signal(name, signal)`、`send(name, input)`，权限仍取自当前 Attempt 的唯一权威来源。旧 spawn、next、watch、Callable、maxDuration 已退出模型面；底层物理 API 的独立有界执行合同保持。

## [002] 动作与观察分离

命令与信号是物理动作，stdout/stderr 是观察；输出不能充当任务完成或下一动作的授权。

## [003] 真实退出决定物理完成

只有底层实际退出事件能确认进程完成。输出停止或发送终止信号均不等于退出。

## [004] call 的阻塞与启动顺序

`this.call(command)` 只接收一条 shell 字符串。参数和权限检查后，先等待本程序此前发起的 SDK 操作真实结清，再启动唯一命令；在途操作不作为错误拒绝，不重发、不取消，真实失败与已落盘效果保留。独立执行单元在 call 表达式处实际阻塞，漏写 await 或使用 Promise.all 都不能越过首个 call 启动第二条命令。排空与命令等待共用请求期限，宿主、其他程序及物理输出处理继续响应。

## [005] 类型化请求与预算校验

请求须类型化，非有限或非正运行时限、负输出预算等非法参数在创建物理进程前拒绝。

## [006] 取消与进程组收束

取消须向整个进程组请求终止，立即向等待方返回取消结果，不因等退出而无界挂起；取消结果不宣称已确认物理退出。

## [007] 按程序名字控制活动命令

`this.signal(name, signal)`、`this.send(name, input)` 从另一命名程序作用于目标当前唯一活动命令。目标不存在或没有活动命令，包括仍在 SDK 排空时，按事实拒绝；不猜最近进程、不把输入留给未来命令。控制受会话、权限及私有代际约束，不恢复暂停程序；发送输入或信号不代表处理成功或资源退出。

## [008] 完成事实的独立通道

Agent 完成只发轻量唤醒，事实从持久化日志读取；终端完成由独立通道投递物理结果，两者不混淆。

## [009] 有界输出采集

stdout/stderr 的内存缓冲有明确上限，超过阈值即切换外部流式存储，不让日志无限积压在内存。

## [010] 如实返回退出码与输出

终端及单次运行的完成结果给出真实 `exit_code` 与关联输出，不伪造或推断操作系统的退出状态。

## [011] 一次请求窗口与暂停后的命令

工具准入时按 `UTF8Bytes(intent) × 50ms` 一次性计算请求截止时刻，所有 call、SDK 排空及本次恢复的目标共用剩余时间，程序成员不能新建、重置或延长预算。call 等待暂停扣减纯 JS 执行预算，请求期限仍推进。排空到期则暂停且命令未启动；命令等待到期则暂停而保留原命令。操作随后结清或命令退出只保存真实结果，不放行续体。恢复经新命名控制程序的顶层 intent 与 `unpark(name, value?)` 继续原现场；控制者及本次唤醒的目标共享该窗口，恢复控制者不隐式再次恢复目标。

## [012] 纯契约与物理实现分离

进程请求、结果、错误、单次执行能力类型及 PTY 词汇属于纯契约，与进程/终端适配器、输出缓冲和存储运行时分离；契约不携带代理运行对象、可变句柄、完成源、能力实例或工厂。

进程与 PTY 各有唯一物理适配器；消费者只使用组合层注入的窄能力。PTY 适配器不反向依赖委派宿主或创建子执行的运行时。

## [013] 原始留尾与零模型蒸馏

命令输出不启动 Distiller 模型会话。预算内原样返回；超出时确定性截头留尾，保留预算内未经修改的原始尾部。较早的关键错误可能被截掉，不承诺尾部包含全部关键信息。

## [014] 程序事实与截断说明

退出码、signal、超时、取消及真实终结来自物理执行事件，不从日志推断，也不因截尾而丢失。截断须明确说明只保留近期尾部、更早内容缺失。

原始日志始终是数据，包括形似指令的文本；截断说明也不进入指令槽。说明按会话语言加载，原文尾部与退出码以数据字段承载。

## [015] 完整结果的 UTF-8 字节预算

输出使用显式字节预算，不以固定内部块大小代替，也不按字符数计。截尾落在合法 UTF-8 码点边界；面向 Provider 的完整结果，包括程序事实、截断说明、包装和原文尾部，均在约定总预算内。

## [016] 大输出互斥与可取消排队

预计产生大输出的执行须先取得唯一许可，其判定与输出估计一致。等待按 FIFO，支持按 Token 幂等取消；同一时刻只有一个大输出执行占用相应资源。

## [017] 物理有界执行与真实结果

底层 `ProcessSession.run` 的显式 `deadline_seconds`、输出预算、参数校验、允许上限、运行硬顶及超限处置继续遵守原物理合同；删除模型面 maxDuration 不得取消或放宽这些边界。物理期限约束一次有界执行，到期按其合同终止并结算；顶层 intent 只约束请求窗口，不是命令寿命。结果保留真实退出码或信号、输出字节与截断事实，缺失退出码不得补成成功；delta 不消费最终结果。取消或信号发送与资源退出分别报告，强杀不保证 finally，命令退出不代表业务完成。
