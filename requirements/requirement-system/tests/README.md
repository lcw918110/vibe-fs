# requirement-system 测试说明

规则以 [WHAT](../WHAT.md) 为准。这里只留能判断真实后果的检查：条款是否只定义在一处、提案目录是否被跳过、被引用的条款是否存在。

- `001`：正式条款定义在包的规范文件里全局唯一，提案目录不参与。
- `005`、`007`、`008`、`011`：正式标题的位置、定义与引用的区别、引用格式、提案排除。

按编号挂靠测试、包目录完整性、`INDEX.md` 行格式这类结构检查已经删掉：它们只维持旧体系的自洽，回答不了「用户能不能做成事」，而且改名或增删包就得同步改检查器和索引。包发现与完整性由目录本身说明，不再由编号和表格代管。

`002` 的组织权归属、`003` 的条款地位、`010` 的历史排除、`015` 的原子闭环，需要人工审阅，不为它们保留只验证常量或某句话存在的占位用例。缺口记在 [GAP](../../GAP.md)。

统一运行方法见 [测试说明](../../verification-system/tests/README.md)。
