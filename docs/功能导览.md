# 万象术功能导览

万象术要回答的不是「怎样再叫来一个模型」，而是几位智能体怎样在同一个工程里把事做完：分工不混，失败能接，最后落在同一份代码上。总流程只有一条——用户打开软件，经过合理交互，万象术弄清需求，把事做完做成，结束。下面的机制都是这条流程上的浪花。

它目前以 OpenCode 插件形式落地，按三层分工演进：

1. **本仓产品面（`wanxiangshu`）**：提示词、工具资源与顶层组装。它直接消费万象理的公开入口；逐步减负，最终不保留程序状态。
2. **万象通（`wanxiangtong`）**：宿主怪癖与生命周期 hook 的翻译，外层目录，暂不开独立仓。
3. **万象理（`wanxiangli`）**：中立核，Smalltalk / A-B-C，状态有主人，不认识具体宿主。

分工看状态归谁，不看「跨宿主」这个字面。离开宿主也有意义的东西，可以进核，也可以只留在本仓组装层；只有对某个宿主才成立的东西，才该待在万象通。

标【程序待改】的地方，是文档写清了、程序还没跟上的部分。

## 一、谁有权做什么

角色是权责边界，不是换一段提示词：

- **Orchestrator**：开辟和接续 Manager 道路，判断互补成果怎样集成、竞争方案怎样取舍，不直接组织源码施工。
- **Manager**：拆任务、派 Engineer、续做固定的 DevOps、看结果。它不亲自改源码、不执行命令。
- **Engineer**：查本地事实，改源码与测试。它不执行真实命令（即使看起来只读），不差遣 DevOps，也不上网。
- **DevOps**：跑命令、构建、测试、查进程。普通缺陷直接修、补测试、重跑；架构与产品决策交回 Manager。
- **Plan**：写规划底稿，不拿全仓写权。
- **Bookkeeper**：整理案例，不调查仓库，不替外层宣布完成。

身份分成 Role、Persona 和物理执行绑定。换模型不等于换角色，也不抹掉原先的承诺。

## 二、委托与并行

- **派工**：Orchestrator 委任 Manager，Manager 派 Engineer，每条道路绑定唯一的 DevOps。
- **换人不换马**：同一个逻辑工作可以换底层模型，历史上下文、承诺与责任不变。
- **Fission**：只有 Engineer 能在允许的子会话里发起多路并发；各路负责不同的局部任务或不重叠的写入区；它们是同一个 Engineer 的多个当下，共享权限与责任，必须由发起者收成一个结果交回 Manager，不能各自宣布完成。

## 三、文件与编程面

改代码是一次严肃操作，不是盲猜替换。文件操作走 `todowrite-for-<role>`：

- 只给 JS 编程面，不给裸 shell。沙箱里用 `cat`、`stat`、`ls`、`rg`、`write`、`mkdir`、`rm`、`mv` 做原子操作。
- 定位用 `where` / `whereAll` 精确匹配源码切片，不靠手工 `indexOf` 或盲正则擦除。
- 读操作登记快照，写操作在落盘前校验文件没被并发改过。
- 定位歧义或等外部结果时 `park` 挂起，之后 `unpark` 接着跑。

## 四、长程工作与上下文

做成才是终点，不是单回合答复：

- 模型自然 stop、单次输出结束只是回合边界；事没做完就继续做。
- 真需要上层或用户决断时，把阻塞说清楚，不假装成功，不静默放弃。
- **Scope 注解**：每次工具调用带打平的 `scope`（`resetScope`｜`keepLast`｜`removeLast`｜`meToo`）。额度是 retention（保留容量），不是回合估计。
  - `scope.kind=resetScope` 结束当前闭环、立新目标，宿主归档走 `ScopeReset.commit`；PairHint 以此为上下文屏障。
  - `removeLast` 出站把上一拍收成一条带教训的 assistant 消息，不物理改持久库。
  - 历史前缀逐字节不变，模型生成的因果才稳。

## 五、模型调度

系统不绑死单一模型。调度层按角色职责挑模型；配额与容量按实账管理，借出的及时归还，物理故障的 provider 及时隔离。

## 六、持久化与恢复

- **变故以事件立身**：核心状态由追加式事件流折出，不直接覆写内存状态。
- **重启重放**：意外退出后重放事件流恢复现场。Applied 不等于已落盘；未知只观察，不盲目重发。
- **单向依赖**：事件抽象与状态机逐步进 `wanxiangli`；宿主信号（OpenCode 的 session-created、chat-message 等）收在 `wanxiangtong`；本仓只管组装与启动，并可直接用核的公开入口。
