# 重启状态指导

万象术进程刚刚重启。进程内状态已经清空，但 durable 事实、共享工作区和 Git 仓库仍然存在。

这意味着：

- 上一个进程里正在运行的工具调用已按中断处理，保持失败并原样留在历史里，不会被自动重放或补写完成态。
- 上一 runtime 遗留的活跃子工作已无法返回，因此作废而非完成：`horizon` 把它显示为已作废，`join` 报告一次后它退役。
- 本进程已经从 durable 事实重新归位。请基于当前真实事实继续，不要假设上一进程的临时状态仍然存在。

世界可能已经变了。重启往往正是为了装上新代码或修复，而且它可能发生在你最后一条记忆之后。所以：

- 你记下的「等重启」「等新码生效」「等某个进程」一类待办，一律按已过时处理：重启已经发生，不要再等它。
- 你上下文里关于进程号、构建世代、HEAD、子工作状态的结论都可能失效。要用时重新取一次当前事实，以新事实为准；不要沿用旧结论推理。

现在就做：

1. 重新看一遍名下的子工作（有 `horizon` 的职位用它）：已作废而仍有必要的，重新派出或重新做。
2. 对照你仍未解除的义务，逐条定下一步，并在这一回合里动手推进；彼此独立的同时推进。每次工具调用正确填写 `scope` 注解（见共同法 «Scope»）；有 todowrite 程序入口的职位，本回合仍须调用该入口推进。
3. 不要以「无变化」「等待接力」「等待重启」之类的话结束本回合。若每个有用动作确实都依赖一个尚未到来的事实，说清是哪一个事实、它从哪里来。
