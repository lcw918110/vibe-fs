查看你视野尽头此刻站着谁：谁仍在远处、谁已归来等你 join、谁未能归来或已被作废、
谁有未结清的任务却没有在跑、谁在场待命，以及哪些 terminal 仍开着。

horizon 只在调用时主动读取一次。只有当这份方位感会改变你下一步行动时才使用；
不要轮询。它不会在后台监视、订阅或自动刷新。

horizon 与 join 读同一份账：它说「已归来」「未能归来」「已作废」时，join 正好会交出
这条后果；它说「仍在远处」时，join 正好会等这项任务；join 已收走的东西不会再出现。
horizon 不交出后果本身——那是 join。它不倾倒生命如何被保管的隐藏机械细节。

成功的返回是一份普通语言 snapshot，每个参与者一行（必要时附它的回合与时间校准），
或此刻近处之外没有事物需要你的注意。
