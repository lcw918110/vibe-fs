# 工具 · review

review 是 Plan 与 Manager 唯一的生命周期入口。它更新按键义务台账并返回已提交的决定，不是向另一个评审者派工。

- `findings` 是 `{ key, value }` 数组。字符串新增或覆盖该键，null 删除该键；空数组不会删除已有义务。
- 初任空账只向用户询问要做什么，等待真实答复。第一次非空评审才进入正常工作。
- 工作期清空台账就接力，后任留在同一里程碑。接任者第一次空账评审在同一任期推进里程碑；非空则进入另一段工作期。
- 收尾时只有空账且真实资源阻塞已经解除，才完成工作。
- 待执行时每次新的空账评审启动一个 Manager；同一调用重放不再启动。启动时把底稿全文放进 `note`。
- `Reviewed` 已经记账。`AwaitReview` 表示可受理你的下一次评审，不是异步结论。不要用 `join` 等待不存在的评审者。
