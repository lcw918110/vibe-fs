Submit the review as a keyed obligation ledger. Each finding is `{ key, value }`: `key` names an obligation, `value` is the remaining work, or `null` to delete the key. An empty ledger asks what the work is until a real obligation is recorded. Clearing the ledger relays the tenure. The successor's first empty review advances the milestone. On close-out, an empty review whose real resource blockers are gone closes the case. In ready-to-execute, each new empty review launches one Manager, and the optional `note` is the full draft handed to it.
