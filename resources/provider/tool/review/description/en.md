Submit the review as a keyed obligation ledger. Each finding is `{ key, value }`: `key` names an obligation, `value` is the remaining work, or `null` to delete the key. An empty ledger asks what the work is until a real obligation is recorded. Once recorded, review returns at once and nobody else does the work: dispatch Engineers and resume `devops` to discharge the obligations, and delete a key with `null` only after returned facts actually discharge it. Clearing the ledger relays the tenure. The successor cannot see this conversation, including the user's words and any `note`; it can only inspect the workspace, so deleting undone obligations leaves it nothing to check and it advances. The successor's first empty review advances the milestone. On close-out, an empty review whose real resource blockers are gone closes the case. In ready-to-execute, each new empty review launches one Manager, and the optional `note` is the full draft handed to it; at any other time `note` reaches no one.
