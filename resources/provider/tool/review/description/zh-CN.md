把评审提交为一份按键义务台账。每条 finding 是 `{ key, value }`：`key` 命名义务，`value` 是剩余工作，或 `null` 删除该键。空台账会询问要做什么，直到记下真实义务。记账后 review 立即返回，没有别人去做这些工作：接着派 Engineer、resume `devops` 去解除义务，等返回的事实真正解除了某一项，才用 `null` 删它。清空台账才接力。后任看不见本次对话，包括用户原话和 `note`，只能检查工作区；把尚未做的义务删掉，等于让它无事可验、直接推进。接任后的第一次空账推进里程碑。收尾时空账且实际资源阻塞已经解除，就结案。「待执行」时每一次新的空账评审启动一个 Manager，可选的 `note` 是交给它的底稿全文；其余时候 `note` 不交给任何人。
