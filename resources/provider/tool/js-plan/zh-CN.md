# 工具 · js-plan

用于对唯一规划产物 P 进行只读查看与受限编辑的 JavaScript 编程面。

## 契约与使用说明

1. **唯一路径**：本工具的作用域严格绑定为当前任务的 `plan.md` 单一文件，严禁访问任何仓库代码或外部目录。
2. **能力原语**：提供 `read()` 读取全文、`edit(patches)` 局部精确补丁以及 `rewrite(content)` 全量覆盖三种操作。
3. **原子发布**：任何写入操作均经排他临时文件写入、flush 后原子替换发布，写入成功即生效。
4. **无环境权限**：沙箱内不暴露环境网络或进程能力，纯受控执行。
