# 万象通

万象通是宿主适配的落点，位于主工作树中，暂不开独立仓库。它负责把 OpenCode、omp 等宿主的消息、工具调用和生命周期事件翻译成产品与万象理能使用的形式，再把结果翻译回宿主。宿主特有的错误与协议差异也留在这里。

万象通只通过万象理的公开入口消费中立能力；万象理不依赖万象通。领域状态归其实际主人，适配层可以拥有翻译和在途协作所需的状态，但不复制领域账本。
